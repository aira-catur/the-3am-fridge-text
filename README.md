Entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) competition on make.fun: a Python program (standard library only, deterministic, no network) that writes one line — the text a smart fridge sends its owner at 3am — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`). The line is 119 characters, within the 1–140 character gate, with no trailing newline.

The line:

> Notification: the cheese you swore was 'for guests' is down to one slice. There are no guests. There never were guests.

## Layout

- `main.py` — entrypoint run by the grader (`python3 main.py`, Python 3.13).
